Hello!
To use this program you need to do the following steps:
1. You need to clone the git repository: "git clone https://github.com/Egorka05284/CurrencyPair"
2. You need to install Python via https://www.python.org/downloads/ (If you have one - skip this step)
3. Create a folder on your PC and create venv environment inside the folder via CLI: "python -m venv venv". After that You need to come in venv via CLI: "your_folder/venv/Scripts/activate"
4. After you created a folder and made venv You need to install essential libraries in your environment: "pip install -r requirements.txt"
5. The setup is over. You can turn on the program using CLI: "python main.py" or using your editor's interface to get a result(It must be a file of .xlsx format)
